Documentation

Mersal is a self-hosted, autonomous SQL agent powered by LLMs. It directly interacts with your PostgreSQL/Neon databases via a conversational interface, automatically generating DDL and DML queries based on plain-language prompts.

Core Philosophy: Mersal is designed to be completely air-gapped from cloud data platforms. Your database connection string remains strictly within your local environment or cluster.

Architecture

The system consists of three primary layers:

  • UI / Terminal: A Next.js (React) front-end providing a chat interface and live schema visualizer.
  • Context Engine (Next.js API Routes): Intercepts commands, fetches the current DB schema (`pg_catalog`), and constructs augmented prompts for the LLM.
  • Execution Engine: Safely executes the returned SQL payloads directly against your database, returning structured output back to the UI.

Docker Deployment

The easiest way to run Mersal is via our pre-built GitHub Container Registry (GHCR) images. This ensures you have the production-ready build with no local dependencies required (other than Docker).

1. Pull the Image

docker pull ghcr.io/<YOUR_USERNAME>/mersal:latest

2. Run the Container

docker run -d \
  -p 3000:3000 \
  -e OPENROUTER_API_KEY=your_openrouter_key \
  -e DATABASE_URL=postgresql://user:pass@host:5432/db \
  --name mersal-agent \
  ghcr.io/<YOUR_USERNAME>/mersal:latest

Navigate to http://localhost:3000 in your browser to access the agent.

Environment Variables

Mersal relies on a few critical environment variables to function correctly. These can be passed via Docker or placed in a .env file if running locally.

Variable Required Description
OPENROUTER_API_KEY Yes* API key for OpenRouter to access LLMs. Can also be set in the UI settings panel.
DATABASE_URL Yes* Full PostgreSQL connection URI. Can also be set in the UI settings panel.

Usage & Commands

Once deployed, you can interact with Mersal as you would a human database administrator.

Examples:

  • Data Retrieval: "Fetch the top 10 users who signed up this week."
  • Schema Modification (DDL): "Create a new table for 'products' with title, price, and a foreign key to categories."
  • Analysis: "What is the average price of products in the electronics category?"
Warning: Mersal executes raw SQL against the provided database. It is highly recommended to run this agent against a staging environment or a branch (if using Neon DB) before executing commands against production data.

Troubleshooting

Unformatted Data Output

If the agent returns raw JSON instead of a formatted table, this means the LLM returned data in an unexpected structure. Ensure your prompt clearly specifies you want data queried from the database.

Connection Errors

Verify your DATABASE_URL. If using Docker on Windows/Mac to connect to a local database, use host.docker.internal instead of localhost.
