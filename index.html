Container Deployment

Mersal is distributed via the GitHub Container Registry (GHCR). Deploy the agent directly into your cluster or local Docker environment. 

# 1. Pull the latest image
docker pull ghcr.io/<YOUR_GITHUB_USERNAME>/mersal:latest

# 2. Initialize container
docker run -d -p 3000:3000 \
  -e OPENROUTER_API_KEY=your_key \
  -e DATABASE_URL=your_postgres_url \
  --name mersal-agent \
  ghcr.io/<YOUR_GITHUB_USERNAME>/mersal:latest

[!] Notice: Replace <YOUR_GITHUB_USERNAME> with your registry namespace. Env vars can also be set via UI.
